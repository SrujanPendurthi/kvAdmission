# kvAdmission

Code and per-query results for *What a KV Cache Retention Signal Must Achieve:
An Oracle-Derived Specification and Screening Test* (`paper/paper.tex`).

```bash
python3 -m pytest -q              # harness tests, incl. bit-identity vs DynamicCache
python3 scripts/make_latex.py     # regenerate every table, figure and number in the paper
```

## Where each result comes from

Every number in the paper is generated by `scripts/make_latex.py` from the
files below; none is typed by hand.

| paper | result file(s) | produced by |
|---|---|---|
| Table 1, oracle vs heuristics | `phase1.json`, `oracle.json`, `scale8b-sweep.json`, `scale8b-oracle.json` | `python -m kvadmission.sweep`, `run_oracle.py` |
| Table 2, coverage (end to end) | `partial-oracle.json` | `run_partial_oracle.py` |
| Table 2, coverage (screen) | `screen-partial-oracle.json` | `screen_partial_oracle.py` (tokeniser only) |
| crowding-law figure | `partial-oracle.json`, `partial-oracle-crowding.json`, `gpu-benchmark.json` | `run_partial_oracle.py [--fp ...]`, `run_benchmark.py --oracle` |
| Table 3 and screen figure | `screen3.json` | `run_screen.py --seeds 8` (runs on a laptop) |
| surprisal pre-registration | `surprisal-needle.json`, `surprisal-qa.json`; predictions in `docs/phase10-prediction.md` | `run_surprisal.py` |
| horizon figure and §6 | `gpu-distance-curve.json`, `horizon-p05.json` | `run_distance_curve.py` (`--rate 0.5` for the latter) |
| Table 4, fragmentation | `fragcount-smollm2.json`, `fragcount-qwen.json` | `run_fragment_count.py` |

All result files are in `results/`, all scripts in `scripts/`; each script's
`--out` default differs from the committed filename, so pass `--out` explicitly. `docs/phase*.md`
are the working findings logs, including the errors made along the way.
